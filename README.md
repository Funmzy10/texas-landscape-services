# Texas Landscape Services

Static site for Texas Landscape Services, Pilot Point, Texas.

- Phone: 469-455-9733

- Yard: 10841 FM 1385, Pilot Point, TX 76258
- Mail: PO Box 1266, Celina, TX 75009

The enquiry form posts to FormSubmit, which emails the office address. The first submission asks that inbox to confirm before messages are delivered. No API key is stored in the repo.

Photographs in `dist/media` were supplied by the client for this project. Captions do not invent addresses, dates, or costs.

To serve locally: open `dist/index.html` or use any static host with `dist` as the output directory.

Point a client-owned domain at the Vercel project. Do not buy a domain from this setup.
